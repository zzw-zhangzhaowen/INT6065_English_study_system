## 三、认证与权限模块详解

### 3.1 用户注册功能

#### 3.1.0 先看注册核心代码

```java
@Override
@Transactional(rollbackFor = Exception.class)
public Long register(RegisterDTO registerDTO) {
    // 第一步：检查用户名是否已存在
    LambdaQueryWrapper<User> wrapper = new LambdaQueryWrapper<>();
    wrapper.eq(User::getUsername, registerDTO.getUsername());
    Long count = userMapper.selectCount(wrapper);
    if (count > 0) {
        throw new RuntimeException("用户名已存在");
    }
    
    // 第二步：创建用户账号
    User user = new User();
    user.setUsername(registerDTO.getUsername());
    user.setPassword(passwordEncoder.encode(registerDTO.getPassword()));
    user.setRole(registerDTO.getRole() != null ? registerDTO.getRole() : "STUDENT");
    user.setStatus(1);
    user.setCreateTime(LocalDateTime.now());
    userMapper.insert(user);
    
    // 第三步：创建用户资料
    UserProfile profile = new UserProfile();
    profile.setUserId(user.getId());
    profile.setNickname(registerDTO.getNickname());
    profile.setEmail(registerDTO.getEmail());
    profile.setPhone(registerDTO.getPhone());
    profile.setAvatar("/default-avatar.png");
    profile.setCreateTime(LocalDateTime.now());
    userProfileMapper.insert(profile);
    
    return user.getId();
}
```

#### 3.1.0.1 这段代码为什么这么写

这段代码的核心思想是：**注册不是只插入一条记录，而是要建立完整的用户档案**。

它完成了三件事：

1. **前置校验**：先查用户名是否已存在，避免重复注册
2. **创建账号**：在 `sys_user` 表中创建登录账号，密码必须加密存储
3. **创建资料**：在 `user_profile` 表中创建用户资料，两个表通过 `user_id` 关联

这样设计的好处是：

- 登录认证只需要查 `sys_user` 表，效率高
- 用户详细信息存 `user_profile` 表，扩展性好
- 两个表分离，符合数据库设计范式

#### 3.1.0.2 为什么要用事务

```java
@Transactional(rollbackFor = Exception.class)
```

注册涉及两张表的插入操作，必须保证原子性：

- 如果账号创建成功，但资料创建失败，会导致数据不一致
- 使用事务后，任何一个步骤失败都会回滚，保证数据完整性

#### 3.1.1 注册流程具体怎么走

##### 第一步：前端表单校验

前端会先进行表单校验，包括：

- 用户名长度 3-20 字符
- 密码长度 6-20 字符
- 两次密码是否一致
- 必填字段是否填写

只有校验通过才会发送请求。

##### 第二步：后端参数校验

```java
@Valid @RequestBody RegisterDTO registerDTO
```

使用 `@Valid` 注解触发 DTO 中的校验规则：

```java
@Data
```

### 3.2 用户登录功能

#### 3.2.0 先看登录核心代码

```java
@Override
public Map<String, Object> login(LoginDTO loginDTO) {
    // 第一步：查询用户
    LambdaQueryWrapper<User> wrapper = new LambdaQueryWrapper<>();
    wrapper.eq(User::getUsername, loginDTO.getUsername());
    User user = userMapper.selectOne(wrapper);
    
    if (user == null) {
        throw new RuntimeException("用户不存在");
    }
    
    // 第二步：校验密码
    if (!passwordEncoder.matches(loginDTO.getPassword(), user.getPassword())) {
        throw new RuntimeException("密码错误");
    }
    
    // 第三步：检查账号状态
    if (user.getStatus() != 1) {
        throw new RuntimeException("账号已被禁用");
    }
    
    // 第四步：生成JWT令牌
    String token = jwtUtils.generateToken(user.getId(), user.getUsername(), user.getRole());
    
    // 第五步：查询用户资料
    LambdaQueryWrapper<UserProfile> profileWrapper = new LambdaQueryWrapper<>();
    profileWrapper.eq(UserProfile::getUserId, user.getId());
    UserProfile profile = userProfileMapper.selectOne(profileWrapper);
    
    // 第六步：组装返回结果
    Map<String, Object> result = new HashMap<>();
    result.put("token", token);
    result.put("userId", user.getId());
    result.put("username", user.getUsername());
    result.put("role", user.getRole());
    result.put("nickname", profile != null ? profile.getNickname() : user.getUsername());
    result.put("avatar", profile != null ? profile.getAvatar() : "/default-avatar.png");
    
    return result;
}
```

#### 3.2.0.1 这段代码为什么这么写

这段代码体现的是**完整的登录认证流程**：

1. **身份验证**：通过用户名+密码验证用户身份
2. **状态检查**：确认账号没有被禁用
3. **令牌生成**：生成 JWT 令牌用于后续请求认证
4. **信息组装**：返回前端需要的用户信息

关键点在于：**登录成功后返回 JWT 令牌，而不是 Session ID**，这是前后端分离项目的标准做法。

#### 3.2.0.2 JWT 令牌是怎么生成的

```java

```

JWT 工具类的核心实现：

```java
public String generateToken(Long userId, String username, String role) {
    Date now = new Date();
    Date expiration = new Date(now.getTime() + expirationTime);
    
    return Jwts.builder()
        .setSubject(String.valueOf(userId))
        .claim("username", username)
        .claim("role", role)
        .claim("userId", userId)
        .setIssuedAt(now)
        .setExpiration(expiration)
        .signWith(SignatureAlgorithm.HS512, secretKey)
        .compact();
}
```

JWT 令牌包含的信息：

- **Subject**：用户ID
- **Claims**：用户名、角色、用户ID等附加信息
- **IssuedAt**：签发时间
- **Expiration**：过期时间
- **Signature**：签名，用于验证令牌真实性

### 3.3 JWT 是怎么发挥作用的

登录成功后，真正维持身份的是 JWT。

#### 3.3.0 先看 JWT 过滤器核心代码

```java
@Component
public class JwtAuthenticationFilter extends OncePerRequestFilter {
    
    @Autowired
    private JwtUtils jwtUtils;
    
    @Override
    protected void doFilterInternal(HttpServletRequest request, 
                                    HttpServletResponse response, 
                                    FilterChain filterChain) 
                                    throws ServletException, IOException {
        String authHeader = request.getHeader("Authorization");
        
        if (authHeader != null && authHeader.startsWith("Bearer ")) {
            String token = authHeader.substring(7);
            
            if (jwtUtils.validateToken(token)) {
                Long userId = jwtUtils.getUserIdFromToken(token);
                String username = jwtUtils.getUsernameFromToken(token);
                String role = jwtUtils.getRoleFromToken(token);
                
                // 创建认证对象
                UsernamePasswordAuthenticationToken authentication =
                    new UsernamePasswordAuthenticationToken(
                        userId,
                        null,
                        Collections.singletonList(new SimpleGrantedAuthority("ROLE_" + role))
                    );
                
                authentication.setDetails(
                    new WebAuthenticationDetailsSource().buildDetails(request)
                );
                
                // 放入安全上下文
                SecurityContextHolder.getContext().setAuthentication(authentication);
            }
        }
        
        filterChain.doFilter(request, response);
    }
}
```

#### 3.3.0.1 这段代码为什么这么写

这段代码的作用不是"登录"，而是"把前端带来的 token 转成后端可识别的登录状态"。

它完成了 4 件事：

1. 从请求头中把 token 取出来
2. 验证 token 是否有效
3. 解析出用户 ID 和角色
4. 把这些身份信息放进 Spring Security 上下文

这样后面任何控制器都能知道：

- 当前请求是谁发来的
- 当前用户是什么角色

#### 3.3.1 前端怎么使用 JWT

前端请求封装在：

- `frontend/src/utils/request.js`

每次发请求前，Axios 请求拦截器都会：

```javascript
// 请求拦截器
request.interceptors.request.use(
  config => {
    const token = localStorage.getItem('token')
    if (token) {
      config.headers['Authorization'] = 'Bearer ' + token
    }
    return config
  },
  error => {
    return Promise.reject(error)
  }
)
```

1. 从 `localStorage` 读取 token
2. 放到请求头 `Authorization`
3. 格式为：`Bearer token值`

#### 3.3.2 后端怎么解析 JWT

后端过滤器处理过程：

1. 读取请求头中的 `Authorization`
2. 判断是否以 `Bearer ` 开头
3. 截取出 token
4. 用 `JwtUtils` 解析 token
5. 取出：userId、username、role
6. 构造 Spring Security 认证对象
7. 放入 `SecurityContextHolder`

#### 3.3.3 这一步做完以后有什么效果

后端就知道"当前请求是谁发来的"。

所以很多接口虽然前端没有传 `userId`，后端依然能通过认证上下文拿到当前登录用户：


#### 4.3.0.2 连续打卡天数是怎么计算的

```java
private int calculateContinuousDays(Long userId) {
    // 查询最近的所有打卡记录，按日期倒序
    LambdaQueryWrapper<DailyCheckIn> wrapper = new LambdaQueryWrapper<>();
    wrapper.eq(DailyCheckIn::getUserId, userId)
           .orderByDesc(DailyCheckIn::getCheckInDate);
    List<DailyCheckIn> checkInList = dailyCheckInMapper.selectList(wrapper);
    
    if (checkInList.isEmpty()) {
        return 0;
    }
    
    int continuousDays = 0;
    LocalDate today = LocalDate.now();
    LocalDate expectedDate = today;
    
    for (DailyCheckIn checkIn : checkInList) {
        LocalDate checkInDate = checkIn.getCheckInDate();
        
        // 检查是否是预期的日期
        if (checkInDate.equals(expectedDate)) {
            continuousDays++;
            expectedDate = expectedDate.minusDays(1);
        } else if (checkInDate.isBefore(expectedDate)) {
            // 出现断档，停止计数
            break;
        }
    }
    
    return continuousDays;
}
```

算法逻辑：

1. 从最近一天开始检查
2. 如果当天有打卡，连续天数 +1
3. 如果当天没有打卡，检查前一天
4. 如果中间出现断档，停止计数

```java
private void autoGenerateQuestions(Long examId, ExamDTO examDTO) {
    // 获取组卷规则
    List<QuestionRuleDTO> rules = examDTO.getQuestionRules();
    
    List<ExamQuestion> examQuestions = new ArrayList<>();
    int sequence = 1;
    
    for (QuestionRuleDTO rule : rules) {
        // 根据规则查询符合条件的题目
        LambdaQueryWrapper<Question> wrapper = new LambdaQueryWrapper<>();
        wrapper.eq(Question::getCategoryId, rule.getCategoryId())
               .eq(Question::getType, rule.getQuestionType())
               .eq(Question::getLevel, rule.getLevel())
               .eq(Question::getStatus, QuestionStatus.ACTIVE.getCode())
               .orderByAsc(Question::getId);
        
        List<Question> questions = questionMapper.selectList(wrapper);
        
        if (questions.size() < rule.getCount()) {
            throw new RuntimeException("题库中符合条件的题目数量不足");
        }
        
        // 随机抽取指定数量的题目
        Collections.shuffle(questions);
        List<Question> selectedQuestions = questions.subList(0, rule.getCount());
        
        // 创建考试题目关联
        for (Question question : selectedQuestions) {
            ExamQuestion examQuestion = new ExamQuestion();
            examQuestion.setExamId(examId);
            examQuestion.setQuestionId(question.getId());
            examQuestion.setSequence(sequence++);
            examQuestion.setScore(rule.getScorePerQuestion());
            examQuestions.add(examQuestion);
        }
    }
    
    // 批量插入
    for (ExamQuestion examQuestion : examQuestions) {
        examQuestionMapper.insert(examQuestion);
    }
}
```

智能组卷的核心逻辑：

1. 根据规则（分类、题型、难度）查询符合条件的题目
2. 随机打乱题目顺序
3. 抽取指定数量的题目
4. 创建考试题目关联

```java
@Override
public PageResult<ExamVO> getExamList(ExamQueryDTO queryDTO) {
    LambdaQueryWrapper<Exam> wrapper = new LambdaQueryWrapper<>();
    
    // 按类型筛选
    if (StrUtil.isNotBlank(queryDTO.getType())) {
        wrapper.eq(Exam::getType, queryDTO.getType());
    }
    
    // 按等级筛选
    if (StrUtil.isNotBlank(queryDTO.getLevel())) {
        wrapper.eq(Exam::getLevel, queryDTO.getLevel());
    }
    
    // 按状态筛选
    if (queryDTO.getStatus() != null) {
        wrapper.eq(Exam::getStatus, queryDTO.getStatus());
    }
    
    // 按标题模糊查询
    if (StrUtil.isNotBlank(queryDTO.getKeyword())) {
        wrapper.like(Exam::getTitle, queryDTO.getKeyword());
    }
    
    // 排序
    wrapper.orderByDesc(Exam::getCreateTime);
    
    // 分页查询
    Page<Exam> page = new Page<>(queryDTO.getCurrent(), queryDTO.getSize());
    Page<Exam> examPage = examMapper.selectPage(page, wrapper);
    
    // 转换为 VO
    List<ExamVO> voList = examPage.getRecords().stream()

        .collect(Collectors.toList());
    
    return new PageResult<>(
        examPage.getTotal(),
        examPage.getCurrent(),
        examPage.getSize(),
        voList
    );
}

private ExamVO convertToVO(Exam exam) {
```

```java
@Override
@Transactional(rollbackFor = Exception.class)
public ExamResultVO submitExam(Long examId, Long userId, List<SubmitAnswerDTO> answers) {
    // 获取考试信息
    Exam exam = examMapper.selectById(examId);
    if (exam == null) {
        throw new RuntimeException("考试不存在");
    }
    
    // 获取考试题目
    LambdaQueryWrapper<ExamQuestion> eqWrapper = new LambdaQueryWrapper<>();
    eqWrapper.eq(ExamQuestion::getExamId, examId)
             .orderByAsc(ExamQuestion::getSequence);
    List<ExamQuestion> examQuestions = examQuestionMapper.selectList(eqWrapper);
    
    // 计算得分
    int totalScore = 0;
    int correctCount = 0;
    List<AnswerRecord> records = new ArrayList<>();
    
    for (int i = 0; i < examQuestions.size(); i++) {
        ExamQuestion eq = examQuestions.get(i);
        Question question = questionMapper.selectById(eq.getQuestionId());
        SubmitAnswerDTO answer = findAnswer(answers, eq.getQuestionId());
        
        // 判断答案是否正确
        boolean isCorrect = false;
        if (answer != null && answer.getUserAnswer() != null) {
            isCorrect = checkAnswer(question, answer.getUserAnswer());
        }
        
        if (isCorrect) {
            totalScore += eq.getScore();
            correctCount++;
        }
        
        // 记录答题详情
        AnswerRecord record = new AnswerRecord();
        record.setExamId(examId);
        record.setUserId(userId);
        record.setQuestionId(question.getId());
        record.setUserAnswer(answer != null ? answer.getUserAnswer() : "");
        record.setIsCorrect(isCorrect);
        record.setScore(isCorrect ? eq.getScore() : 0);
        record.setAnswerTime(LocalDateTime.now());
        records.add(record);
    }
    
    // 批量保存答题记录
    for (AnswerRecord record : records) {
        answerRecordMapper.insert(record);
    }
    
    // 组装返回结果
    ExamResultVO resultVO = new ExamResultVO();
    resultVO.setExamId(examId);
    resultVO.setTotalScore(totalScore);
    resultVO.setCorrectCount(correctCount);
    resultVO.setTotalCount(examQuestions.size());
    resultVO.setPass(totalScore >= exam.getPassScore());
    resultVO.setRecords(records);
    
    return resultVO;
}

private boolean checkAnswer(Question question, String userAnswer) {
    String correctAnswer = question.getCorrectAnswer();
    if (correctAnswer == null || userAnswer == null) {
        return false;
    }
    
    // 根据题型判断
    switch (question.getType()) {
        case SINGLE_CHOICE:
        case JUDGE:
            // 单选、判断：直接比较
            return correctAnswer.trim().equalsIgnoreCase(userAnswer.trim());
        case MULTIPLE_CHOICE:
            // 多选：排序后比较
            String[] correctArr = correctAnswer.split(",");
            String[] userArr = userAnswer.split(",");
            Arrays.sort(correctArr);
            Arrays.sort(userArr);
            return Arrays.equals(correctArr, userArr);
        case FILL_BLANK:
            // 填空：忽略大小写比较
            return correctAnswer.trim().equalsIgnoreCase(userAnswer.trim());
        default:
            return false;
    }
}
```

#### 5.3.0.3 这段代码为什么这么写

自动判分的核心逻辑：

1. 遍历每道题目
2. 获取用户答案
3. 与正确答案比对
4. 记录答题详情
5. 计算总分

不同题型的判分规则不同：

- **单选题**：直接比较答案
- **多选题**：排序后比较，必须完全一致
- **判断题**：直接比较
- **填空题**：忽略大小写比较

```java
@Override
public List<RankingVO> getExamRanking(Long examId) {
    // 查询该考试的所有答题记录
    LambdaQueryWrapper<AnswerRecord> wrapper = new LambdaQueryWrapper<>();
    wrapper.eq(AnswerRecord::getExamId, examId);
    List<AnswerRecord> records = answerRecordMapper.selectList(wrapper);
    
    // 按用户分组统计总分
    Map<Long, Integer> userScores = new HashMap<>();
    Map<Long, LocalDateTime> userTimes = new HashMap<>();
    
    for (AnswerRecord record : records) {
        Long userId = record.getUserId();
        userScores.merge(userId, record.getScore(), Integer::sum);
        userTimes.putIfAbsent(userId, record.getAnswerTime());
    }
    
    // 按分数排序
    List<Map.Entry<Long, Integer>> sorted = userScores.entrySet().stream()
        .sorted((a, b) -> b.getValue().compareTo(a.getValue()))
        .collect(Collectors.toList());
    
    // 组装排名数据
    List<RankingVO> rankings = new ArrayList<>();
    int rank = 1;
    for (Map.Entry<Long, Integer> entry : sorted) {
        Long userId = entry.getKey();
        User user = userMapper.selectById(userId);
        if (user == null) continue;
        
        RankingVO rankingVO = new RankingVO();
        rankingVO.setRank(rank++);
        rankingVO.setUserId(userId);
        rankingVO.setNickname(user.getNickname());
        rankingVO.setAvatar(user.getAvatar());
        rankingVO.setScore(entry.getValue());
        rankingVO.setAnswerTime(userTimes.get(userId));
        rankings.add(rankingVO);
        
        // 只取前100名
        if (rank > 100) break;
    }
    
    return rankings;
}
```

#### 5.5.0.1 这段代码为什么这么写

排名计算的核心逻辑：

1. 查询该考试的所有答题记录
2. 按用户ID分组，累加每道题的得分
3. 按总分从高到低排序
4. 组装排名数据，包含用户信息和分数

```java
private List<QuestionCategoryVO> buildTree(List<QuestionCategoryVO> all, Long parentId) {
    List<QuestionCategoryVO> children = new ArrayList<>();

        if (parentId.equals(vo.getParentId())) {

    }

}
```

#### A.2.2 ExamServiceImpl 实现类

```java
@Service
public class ExamServiceImpl implements ExamService {
    
    @Autowired
    private ExamMapper examMapper;
    
    @Autowired
    private ExamQuestionMapper examQuestionMapper;
    
    @Autowired
    private QuestionMapper questionMapper;
    
    @Autowired
    private AnswerRecordMapper answerRecordMapper;
    
    @Override
    @Transactional(rollbackFor = Exception.class)
    public Long createExam(ExamDTO examDTO, Long creatorId) {
        // 创建考试
        Exam exam = new Exam();
        BeanUtils.copyProperties(examDTO, exam);
        exam.setCreatorId(creatorId);
        exam.setStatus(ExamStatus.DRAFT.getCode());
        exam.setCreateTime(LocalDateTime.now());
        examMapper.insert(exam);
        
        // 关联题目
        if (examDTO.getQuestionIds() != null && !examDTO.getQuestionIds().isEmpty()) {
            List<Long> questionIds = examDTO.getQuestionIds();
            for (int i = 0; i < questionIds.size(); i++) {
                ExamQuestion eq = new ExamQuestion();
                eq.setExamId(exam.getId());
                eq.setQuestionId(questionIds.get(i));
                eq.setSequence(i + 1);
                eq.setScore(examDTO.getQuestionScores().get(i));
                examQuestionMapper.insert(eq);
            }
        }
        
        return exam.getId();
    }
    
    @Override
    public PageResult<ExamVO> getExamList(ExamQueryDTO queryDTO) {
        LambdaQueryWrapper<Exam> wrapper = new LambdaQueryWrapper<>();
        
        if (StrUtil.isNotBlank(queryDTO.getType())) {
            wrapper.eq(Exam::getType, queryDTO.getType());
        }
        if (StrUtil.isNotBlank(queryDTO.getLevel())) {
            wrapper.eq(Exam::getLevel, queryDTO.getLevel());
        }
        if (queryDTO.getStatus() != null) {
            wrapper.eq(Exam::getStatus, queryDTO.getStatus());
        }
        if (StrUtil.isNotBlank(queryDTO.getKeyword())) {
            wrapper.like(Exam::getTitle, queryDTO.getKeyword());
        }
        
        wrapper.orderByDesc(Exam::getCreateTime);
        
        Page<Exam> page = new Page<>(queryDTO.getCurrent(), queryDTO.getSize());
        Page<Exam> examPage = examMapper.selectPage(page, wrapper);
        
        List<ExamVO> voList = examPage.getRecords().stream()
            .map(this::convertToVO)
            .collect(Collectors.toList());
        
        return new PageResult<>(examPage.getTotal(), examPage.getCurrent(), 
            examPage.getSize(), voList);
    }
    
    private ExamVO convertToVO(Exam exam) {
        ExamVO vo = new ExamVO();
        BeanUtils.copyProperties(exam, vo);
        
        // 查询题目数量
        LambdaQueryWrapper<ExamQuestion> wrapper = new LambdaQueryWrapper<>();
        wrapper.eq(ExamQuestion::getExamId, exam.getId());
        Long questionCount = examQuestionMapper.selectCount(wrapper);
        vo.setQuestionCount(questionCount);
        
        return vo;
    }
}
```

## 附录D：常见错误及解决方案

### D.1 后端常见错误

#### D.1.1 数据库连接失败

错误信息：
```
com.mysql.cj.jdbc.exceptions.CommunicationsException: Communications link failure
```

解决方案：
1. 检查 MySQL 服务是否启动
2. 检查数据库连接地址、用户名、密码是否正确
3. 检查防火墙是否阻止了连接

#### D.1.2 JWT Token 无效

错误信息：
```
io.jsonwebtoken.JwtException: JWT expired
```

解决方案：
1. Token 已过期，需要重新登录
2. 检查 Token 是否正确传递
3. 检查 JWT 密钥配置是否正确

### D.2 前端常见错误

#### D.2.1 跨域问题

错误信息：
```
Access to XMLHttpRequest at 'xxx' from origin 'xxx' has been blocked by CORS policy
```

解决方案：
1. 在后端配置 CORS
2. 使用 Vite 的代理功能
3. 确保 Spring Security 允许跨域请求

#### D.2.2 组件渲染错误

错误信息：
```
Cannot read properties of undefined (reading 'xxx')
```

解决方案：
1. 检查数据是否正确加载
2. 使用可选链操作符 `?.`
3. 添加默认值处理

```java
    }
```

```java
     * 判断字符串是否不为空
     */
    public static boolean isNotEmpty(String str) {
        return !isEmpty(str);

     * 截取字符串
     */
    public static String truncate(String str, int maxLength) {
        if (isEmpty(str) || str.length() <= maxLength) {
            return str;
        }
        return str.substring(0, maxLength) + "...";
    }
    
    /**
     * 生成随机字符串
     */
    public static String randomString(int length) {
        String chars = "ABCDEFGHIJKLMNOPQRSTUVWXYZabcdefghijklmnopqrstuvwxyz0123456789";
        StringBuilder sb = new StringBuilder();
        Random random = new Random();
        for (int i = 0; i < length; i++) {
            sb.append(chars.charAt(random.nextInt(chars.length())));
        }
        return sb.toString();
    }
    
    /**
     * 首字母大写
     */
    public static String capitalize(String str) {
        if (isEmpty(str)) {
            return str;
        }
        return str.substring(0, 1).toUpperCase() + str.substring(1);
    }
```

```java
@Component
public class FileUploadUtil {
    
    @Value("${file.upload.path}")
    private String uploadPath;
    
    @Value("${file.upload.max-size}")
    private long maxSize;
    
    /**
     * 上传文件
     */
    public String uploadFile(MultipartFile file, String directory) throws IOException {
        // 检查文件是否为空
        if (file.isEmpty()) {
            throw new RuntimeException("文件不能为空");
        }
        
        // 检查文件大小
        if (file.getSize() > maxSize) {
            throw new RuntimeException("文件大小超过限制");
        }
        
        // 获取文件扩展名
        String originalFilename = file.getOriginalFilename();
        String extension = originalFilename.substring(originalFilename.lastIndexOf("."));
        
        // 生成新文件名
        String newFilename = UUID.randomUUID().toString() + extension;
        
        // 创建目录
        String dirPath = uploadPath + "/" + directory;
        File dir = new File(dirPath);
        if (!dir.exists()) {
            dir.mkdirs();
        }
        
        // 保存文件
        File destFile = new File(dirPath + "/" + newFilename);
        file.transferTo(destFile);
        
        // 返回相对路径
        return "/uploads/" + directory + "/" + newFilename;
    }
    
    /**
     * 删除文件
     */
    public boolean deleteFile(String filePath) {
        if (isEmpty(filePath)) {
            return false;
        }
        File file = new File(uploadPath + filePath.replace("/uploads", ""));
        if (file.exists()) {
            return file.delete();
        }
        return false;
    }
}
```

```java
     * 处理业务异常
     */
    @ExceptionHandler(RuntimeException.class)
    public Result<Void> handleRuntimeException(RuntimeException e) {
        logger.error("业务异常：{}", e.getMessage());
        return Result.error(e.getMessage());
    }
    
    /**
     * 处理参数校验异常
     */
    @ExceptionHandler(MethodArgumentNotValidException.class)
    public Result<Void> handleValidationException(MethodArgumentNotValidException e) {
        BindingResult bindingResult = e.getBindingResult();
        String message = bindingResult.getFieldErrors().stream()
            .map(FieldError::getDefaultMessage)
            .collect(Collectors.joining(", "));
        logger.error("参数校验失败：{}", message);
        return Result.error(message);
    }
    
    /**
     * 处理权限异常
     */
    @ExceptionHandler(AccessDeniedException.class)
    public Result<Void> handleAccessDeniedException(AccessDeniedException e) {
        logger.error("权限不足：{}", e.getMessage());
        return Result.error("权限不足");
    }
    
    /**
     * 处理其他异常
     */
    @ExceptionHandler(Exception.class)
    public Result<Void> handleException(Exception e) {
```

```java
    public void afterConnectionEstablished(WebSocketSession session) {
        Long userId = getUserIdFromSession(session);
        sessions.put(userId, session);
    }
    
    @Override
    protected void handleTextMessage(WebSocketSession session, TextMessage message) {
        // 处理消息
        JSONObject data = JSON.parseObject(message.getPayload());
        String type = data.getString("type");
        
        switch (type) {
            case "chat":
                handleChat(data);
                break;
            case "poll":
                handlePoll(data);
                break;
            default:
                break;
        }
    }
    
    @Override
    public void afterConnectionClosed(WebSocketSession session, CloseStatus status) {
        Long userId = getUserIdFromSession(session);
        sessions.remove(userId);
    }
    
    /**
     * 广播消息
     */
    public void broadcast(Long classroomId, String message) {
        sessions.values().forEach(session -> {
            try {
                session.sendMessage(new TextMessage(message));
            } catch (IOException e) {
                e.printStackTrace();
            }
        });
    }
}
```

```java
@Service
public class LearningReportService {
    
    @Autowired
    private AnswerRecordMapper answerRecordMapper;
    
    @Autowired
    private DailyCheckInMapper dailyCheckInMapper;
    
    /**
     * 生成周报告
     */
    public LearningReportVO generateWeeklyReport(Long userId) {
        LearningReportVO report = new LearningReportVO();
        
        // 获取本周数据
        LocalDate today = LocalDate.now();
        LocalDate weekStart = today.with(DayOfWeek.MONDAY);
        LocalDate weekEnd = today.with(DayOfWeek.SUNDAY);
        
        // 统计答题数
        int weeklyAnswerCount = countAnswersBetween(userId, weekStart, weekEnd);
        report.setWeeklyAnswerCount(weeklyAnswerCount);
        
        // 统计正确率
        double weeklyAccuracy = calculateAccuracyBetween(userId, weekStart, weekEnd);
        report.setWeeklyAccuracy(weeklyAccuracy);
        
        // 统计学习天数
        int studyDays = countStudyDaysBetween(userId, weekStart, weekEnd);
        report.setWeeklyStudyDays(studyDays);
        
        // 各题型正确率

        report.setTypeAccuracy(typeAccuracy);
        
        // 每日学习趋势
        List<DailyStudyVO> dailyTrend = calculateDailyTrend(userId, weekStart, weekEnd);
        report.setDailyTrend(dailyTrend);
        
        // 学习建议
        List<String> suggestions = generateSuggestions(report);
        report.setSuggestions(suggestions);
        
        return report;
```
