## 🔐 登录问题

### 问题1：管理员账号登录提示"用户名或密码错误"

#### 错误日志示例
```
2026-01-24 04:10:26 [http-nio-8080-exec-7] ERROR c.e.l.c.e.GlobalExceptionHandler - 业务异常: 用户名或密码错误

==>  Preparing: SELECT id,username,password,... FROM sys_user WHERE deleted=0 AND (username = ?)
==> Parameters: admin(String)
<==      Total: 1
```

#### 根本原因
数据库中存储的BCrypt密码hash与预期的hash不匹配：
- **数据库实际hash**：`$2a$10$N.zmdr9k7uOCQb376NoUnuTJ8iAt6Z5EHsM8lE9lBOsl7iKTVKIUi`
- **SQL脚本预期hash**：`$2a$10$XNZv3GdQT7ZJuBhWd5aSQey2V5gR6.VLKhJ7hHMvj8X4EqGKkW7/S`（对应密码：admin123）

后端使用 `BCryptPasswordEncoder.matches(password, hash)` 验证密码，hash不匹配会导致验证失败。

#### 解决方案

**方法1：使用SQL脚本（推荐）**

```powershell
# 进入SQL脚本目录
cd d:\protect\接单\dan_3\test\backend\src\main\resources\sql

# 执行修复脚本
Get-Content fix-admin-password.sql | mysql -uroot -p123456
```

**方法2：直接执行SQL命令**

```powershell
# PowerShell环境
mysql -uroot -p123456 -e "USE english_learning; UPDATE sys_user SET password = '\$2a\$10\$XNZv3GdQT7ZJuBhWd5aSQey2V5gR6.VLKhJ7hHMvj8X4EqGKkW7/S' WHERE username = 'admin';"
```

**方法3：使用MySQL客户端**

```sql
USE english_learning;

UPDATE sys_user 
SET password = '$2a$10$XNZv3GdQT7ZJuBhWd5aSQey2V5gR6.VLKhJ7hHMvj8X4EqGKkW7/S' 
WHERE username = 'admin';

-- 验证更新
SELECT id, username, '密码已更新为: admin123' as message 
FROM sys_user 
WHERE username = 'admin';
```

#### 验证修复
1. 刷新浏览器页面
2. 使用账号 `admin` / 密码 `admin123` 登录
3. 应该成功进入管理员后台

#### 技术说明

**BCrypt加密机制：**
- BCrypt是一种单向加密算法，每次加密相同的密码会生成不同的hash
- Hash格式：`$2a$10$...`（$2a=算法版本，$10=强度因子）
- 验证逻辑：`BCryptPasswordEncoder.matches("admin123", hash)` 返回 true/false

**后端验证代码位置：**
```
backend/src/main/java/com/english/learning/service/AuthService.java:44
if (!passwordEncoder.matches(request.getPassword(), user.getPassword())) {
    throw new BusinessException("用户名或密码错误");
}
```

## 🚀 启动问题

### 问题4：后端启动失败

#### 常见原因
1. **端口被占用**
```powershell
# 检查端口占用
netstat -ano | findstr :8080

# 结束占用进程
taskkill /PID <进程ID> /F
```

2. **依赖问题**
```bash
cd backend
mvn clean install -DskipTests
```

3. **数据库连接失败**
- 检查MySQL服务是否启动
- 验证数据库账号密码
- 确认数据库名称是否正确

### 问题5：前端启动失败

cd frontend

# 清理node_modules
rm -rf node_modules package-lock.json

npm install

npm run dev

#### 解决方案
1. 使用HTTPS传输
2. 设置Token有效期
3. 实现Token刷新机制
4. 前端退出时清除Token

### 问题12：密码强度不足

#### 增强密码策略
```java
// 密码验证正则
private static final String PASSWORD_PATTERN = 
    "^(?=.*[a-z])(?=.*[A-Z])(?=.*\\d)(?=.*[@$!%*?&])[A-Za-z\\d@$!%*?&]{8,}$";
```
